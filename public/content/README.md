# Aviix Media content

These JSON files drive all page copy and can be edited by Decap CMS.

- `site.json` — global nav, brand, footer, socials
- `home.json` — home page sections
- `about.json` — about page hero + features
- `contact.json` — contact page

Image fields accept an absolute URL (e.g. `/images/hero.jpg`). Empty string
renders a styled dark placeholder at the correct aspect ratio.
